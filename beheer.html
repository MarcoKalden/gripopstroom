Hoe maak ik een GitHub-sleutel?
  1. Ga naar github.com/settings/personal-access-tokens/new (ingelogd als eigenaar van de repo).
  2. Naam: bijvoorbeeld Beheer website. Kies een vervaldatum, bijvoorbeeld over een jaar.
  3. Bij Repository access: kies Only select repositories en dan gripopstroom.
  4. Bij Permissions → Repository permissions: zet Contents op Read and write. Verder niets.
  5. Klik op Generate token en kopieer de sleutel. GitHub toont hem maar één keer.

Bewaar de sleutel als een wachtwoord. Kwijt of uitgelekt? Verwijder hem op dezelfde GitHub-pagina en maak een nieuwe.
